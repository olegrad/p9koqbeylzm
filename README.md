# Cycle Partner

Личное PWA: по датам цикла показывает текущую фазу, мягкие подсказки с источниками и ведёт дневник наблюдений. Все данные хранятся только на телефоне (localStorage). В репозитории нет личных данных.

## Установка на iPhone

1. Открой ссылку GitHub Pages в **Safari**.
2. «Поделиться» → «На экран Домой».
3. Запускай с иконки. У приложения на главном экране своё хранилище, отдельное от вкладки Safari: данные, введённые во вкладке, в иконку не переедут. Переноси их через экспорт и импорт.

## Разработка

Без сборки и без зависимостей: обычные ES-модули.

```bash
node tools/serve.mjs
```

Приложение откроется на http://localhost:8765.

| Путь | Что там |
| --- | --- |
| `js/cycle.js` | расчёт фаз, прогноза и сводки по отметкам |
| `js/store.js` | хранение, схема данных, миграции, импорт |
| `js/app.js` | экраны и обработчики |
| `js/push-check.js` | ранняя проверка уведомлений и push на телефоне |
| `i18n/ru.json` | все строки интерфейса |
| `content/ru/phases.json` | тексты по фазам: у каждого утверждения есть `source` и `confidence` |
| `content/ru/phases-review.md` | те же тексты в читаемом виде для ревью (генерируется) |
| `sw.js` | офлайн-режим и обновления |
| `tools/` | генерация иконок и документа для ревью, локальный сервер |

После правки `phases.json`:

```bash
node tools/phases-review.mjs
```

## Выпуск обновления

1. Подними `VERSION` в `js/version.js` и `CACHE` в `sw.js`.
2. Если добавлен новый файл, впиши его в `ASSETS` в `sw.js`.
3. `git push`: GitHub Pages опубликует за минуту-две. Телефон подхватит новую версию при следующем запуске приложения, иногда только со второго запуска.

## Данные

Формат JSON с полем `schema`. Функция `migrate()` в `js/store.js` приводит старые версии и импортируемые файлы к текущей схеме, поэтому при изменении формата правь её, а не ломай старые копии.
